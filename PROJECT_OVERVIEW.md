# Kitty Witty — Обзор проекта

## 1. Общее описание

**Kitty Witty** — это 2D-игра про котёнка-дайвера, который строит самодельный водолазный костюм, чтобы исследовать подводный мир. Игра выполнена на **Phaser 3.90**, **TypeScript** и **Vite 6**. Разрешение — **1920×1080**.

Игрок управляет котёнком в пяти локациях: школа, пляж, детская, гараж и море. В каждой локации нужно находить предметы, решать головоломки и мини-игры, чтобы собрать все части костюма и открыть доступ к морю.

## 2. Архитектура

Проект построен на **классической сцено-ориентированной архитектуре Phaser**. Все игровые сцены наследуются от абстрактного класса `BaseScene`, который инкапсулирует общую логику: загрузку ресурсов, создание игрока, препятствий, зон взаимодействия и UI.

### Основные слои:
- **Сцены** (`src/scenes/`) — игровые локации и загрузочный экран.
- **UI-система** (`src/ui/`) — интерфейс: меню, модальные окна, диалоги, тосты, крафтинг.
- **Мини-игры** (`src/minigames/`) — четыре отдельные механики.
- **Менеджеры** (`src/managers/`) — управление инвентарём и другими глобальными состояниями.
- **Объекты** (`src/objects/`) — игрок и геометрические примитивы.
- **Утилиты** (`src/utils/`) — константы и вспомогательные классы.

## 3. Структура файлов

### 3.1. `src/main.ts`

Точка входа. Создаёт конфигурацию Phaser, подключает все сцены и запускает игру.

**Роль:** инициализация Phaser.Game, регистрация сцен, передача глобальных настроек.

**Связи:** импортирует все сцены из `src/scenes/`.

### 3.2. `src/utils/constants.ts`

Содержит все константы игры: размеры, ключи сцен, ключи ассетов, названия событий, параметры игрока и т.д.

**Роль:** единый источник правды для строк и чисел, чтобы избежать магических значений.

**Связи:** используется всеми сценами, UI и мини-играми.

### 3.3. `src/utils/Scene_Menu.ts`

Вспомогательный класс для создания пунктов меню (кнопок) в UI. Позволяет быстро создавать интерактивные элементы с обработчиками.

**Роль:** упрощает создание кнопок в модальных окнах и меню.

**Связи:** используется UI-компонентами.

### 3.4. `src/objects/player.ts`

Класс игрока (котёнок). Наследуется от `Phaser.Physics.Arcade.Sprite`. Управляет анимациями, перемещением, взаимодействием с объектами.

**Роль:** представляет игрока в каждой сцене.

**Связи:** создаётся в `BaseScene`, используется во всех игровых сценах.

### 3.5. `src/objects/geometry.ts`

Набор геометрических примитивов (прямоугольники, круги) для создания препятствий и зон взаимодействия без тайловых карт.

**Роль:** упрощает создание коллайдеров и триггеров.

**Связи:** используется в `BaseScene` и конкретных сценах.

### 3.6. `src/managers/inventory_manager.ts`

Менеджер инвентаря. Хранит предметы, которые игрок собирает. Реализован как синглтон.

**Роль:** управление предметами, добавление, удаление, проверка наличия.

**Связи:** используется UI (рюкзак), сценами (при подборе предметов) и крафтингом.

### 3.7. `src/scenes/BaseScene.ts`

Абстрактный класс, от которого наследуются все игровые сцены. Содержит общую логику:
- загрузка ресурсов (переопределяется в наследниках)
- создание игрока
- создание препятствий (коллайдеров)
- создание зон взаимодействия
- инициализация UI
- обработка переходов между сценами

**Роль:** уменьшает дублирование кода, задаёт единый шаблон.

**Связи:** наследуется всеми сценами, использует `player.ts`, `geometry.ts`, UI-компоненты.

### 3.8. `src/scenes/ClassroomScene.ts`

Локация «Школа». Игрок появляется здесь в начале игры. Содержит интерактивные объекты: парты, доска, шкафчик. Здесь можно найти первый предмет для костюма (например, маску).

**Роль:** стартовая локация, обучение основам управления.

**Связи:** наследует `BaseScene`, использует `InventoryManager`.

### 3.9. `src/scenes/BeachScene.ts`

Локация «Пляж». Здесь игрок находит части костюма (например, ласты) и может открыть мини-игру «Shell Hunt».

**Роль:** вторая локация, вводит мини-игры.

**Связи:** наследует `BaseScene`, запускает мини-игру.

### 3.10. `src/scenes/ChildrenRoomScene.ts`

Локация «Детская». Здесь находится мини-игра «Memory Match» и предметы для костюма (например, трубка).

**Роль:** локация с головоломкой на память.

**Связи:** наследует `BaseScene`, запускает мини-игру.

### 3.11. `src/scenes/GarageScene.ts`

Локация «Гараж». Здесь находится мини-игра «Fix Gadget» и предметы (например, баллон с воздухом). Также здесь можно скрафтить часть костюма.

**Роль:** локация для крафта и починки механизмов.

**Связи:** наследует `BaseScene`, использует крафтинг-UI.

### 3.12. `src/scenes/SeaScene.ts`

Локация «Море». Открывается после того, как собран весь костюм. Здесь игрок плавает и исследует подводный мир. Финальная локация.

**Роль:** финальная цель игры.

**Связи:** наследует `BaseScene`, проверяет наличие всех предметов костюма.

### 3.13. `src/ui/` — UI-компоненты

#### `src/ui/game_ui.ts`

Управляет всеми UI-элементами: меню, модальные окна, диалоги, тосты.

**Роль:** централизованное создание и управление интерфейсом.

**Связи:** используется в `BaseScene` и конкретных сценах.

#### `src/ui/compact_menu.ts`

Компактное меню в углу экрана: кнопки «Рюкзак», «Карта», «Дневник».

**Роль:** быстрый доступ к инвентарю, карте и дневнику.

**Связи:** использует `InventoryManager`, карту локаций.

#### `src/ui/modal.ts`

Модальные окна для диалогов, подсказок, подтверждений.

**Роль:** показ информации поверх игры.

**Связи:** используется для диалогов с NPC и сообщений.

#### `src/ui/dialogue_box.ts`

Система диалогов с посимвольным выводом текста.

**Роль:** отображение реплик персонажей.

**Связи:** используется в сценах для общения с NPC.

#### `src/ui/toast.ts`

Всплывающие уведомления (тосты) для подсказок и событий.

**Роль:** ненавязчивые сообщения игроку.

**Связи:** используется при подборе предметов, открытии локаций.

#### `src/ui/crafting_UI.ts`

Интерфейс крафта: показывает доступные рецепты и позволяет создавать предметы.

**Роль:** создание частей костюма из собранных материалов.

**Связи:** использует `InventoryManager`.

#### `src/ui/game_ui_state.ts`

Модуль, который хранит состояние UI в Phaser Registry. Позволяет синхронизировать открытые окна между сценами.

**Роль:** глобальное состояние интерфейса.

**Связи:** используется UI-менеджером и сценами.

### 3.14. `src/minigames/` — мини-игры

#### `src/minigames/memory_match.ts`

Мини-игра «Найди пары». Игрок открывает карточки и ищет одинаковые.

**Роль:** тренировка памяти, награда — предмет.

**Связи:** запускается из ClassroomScene.

#### `src/minigames/shell_hunt.ts`

Мини-игра «Охота за ракушками» (арканоид). Игрок отбивает мяч, чтобы собрать ракушки.

**Роль:** аркадная механика, награда — предмет.

**Связи:** запускается из BeachScene.

#### `src/minigames/puzzle_15.ts`

Мини-игра «Пятнашки» с паролем. Игрок собирает картинку, получает пароль для сейфа.

**Роль:** головоломка, открывает доступ к предмету.

**Связи:** запускается из ChildrenRoomScene.

#### `src/minigames/fix_gadget.ts`

Мини-игра «Почини механизм». Игрок соединяет провода или крутит шестерёнки.

**Роль:** логическая мини-игра, награда — предмет.

**Связи:** запускается из GarageScene.

## 4. Игровой цикл

1. **Запуск игры** — `main.ts` создаёт игру, загружается `ClassroomScene` (первая сцена).
2. **Исследование локаций** — игрок перемещается по сцене, взаимодействует с объектами (клавиша E).
3. **Сбор предметов** — при взаимодействии с объектами игрок получает предметы в инвентарь (через `InventoryManager`).
4. **Мини-игры** — в определённых местах игрок запускает мини-игры. За успешное прохождение получает награду (предмет или часть костюма).
5. **Крафт** — в гараже игрок может скрафтить недостающие части костюма из собранных материалов.
6. **Открытие новых локаций** — некоторые локации (пляж, детская, гараж) открываются после выполнения условий.
7. **Сборка костюма** — когда все части костюма собраны, игрок может надеть его и перейти в море.
8. **Море** — финальная локация, где игрок плавает и завершает игру.

## 5. Карта локаций

Карта представлена изображением `city-map.png` в UI. На ней кликабельные области, соответствующие локациям. При клике игрок перемещается в выбранную локацию (если она открыта).

## 6. Шрифты

Шрифт **Galmuri7** (Rus by rigbikkk) загружается через FontFace API в `main.ts`. Используется во всех UI-элементах.

## 7. Сборка и запуск

- `npm run dev` — запуск в режиме разработки с горячей перезагрузкой.
- `npm run build` — продакшен-сборка.
- `npm run dev-nolog` — dev без логирования.
- `npm run build-nolog` — build без логирования.

## 8. Рекомендации для разработчика

- Все новые сцены должны наследоваться от `BaseScene`.
- Для добавления нового предмета — обнови `InventoryManager` и константы.
- Для новой мини-игры — создай класс в `src/minigames/` и запускай его из сцены.
- UI-компоненты должны быть переиспользуемыми и не зависеть от конкретной сцены.
- Следуй существующему стилю кода (именование, структура).

## 9. Заключение

Проект имеет чёткую модульную структуру, что упрощает добавление новых локаций, предметов и мини-игр. Основная логика вынесена в `BaseScene` и менеджеры, поэтому новые сцены создаются быстро и без дублирования кода.
