# Папка для сцен

Структура папки: 

scenes/

boot_scene.ts 
*Первая сцена. Загружает изображения. Музыку. Шрифты.*
menu_scene.ts
*Главное меню с кнопкой **Play***

classroom_scene.ts
*Начало игры. Урок. Диалог с учителем.*

garage_scene.ts
*Гараж, где берется инвентарь для костюма*

bedroom_scene.ts 
*Комната котёнка. Дневник. Инвентарь.*

beach_scene.ts
*Берег с рыбаками*

dive_scene.ts
*Подводный мир.*

ending_scene.ts
*Концовка*
