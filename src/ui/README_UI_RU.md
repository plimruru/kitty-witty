# UI Kitty Witty

## Текущее решение

Интерфейс построен вокруг игрового поля. Игра запускается сразу, а на экране
постоянно находится только квадратная кнопка `☰` в правом верхнем углу.

Убраны:

- стартовый экран;
- верхняя панель;
- нижняя панель;
- номер главы и название локации;
- счётчик предметов;
- отдельная кнопка паузы;
- кнопка подсказки.

Все панели, кнопки, карточки и модальные окна имеют прямые углы.

## Компактное меню

`compact_menu.ts` повторяет поведение меню из `src/utils/Scene_Menu.ts`:

- небольшая кнопка в правом верхнем углу;
- панель раскрывается вниз;
- используются `alpha` и `scaleY`;
- длительность анимации — 200 мс;
- меню не разворачивается на весь экран.

В меню три пункта:

1. Рюкзак.
2. Карта.
3. Дневник.

Каждый пункт открывает интерактивное модальное окно. Окно закрывается:

- крестиком;
- клавишей `Esc`;
- кликом по затемнённой области вне окна.

## Подключение

В `preload` сцены нужно поставить карту в очередь загрузки:

```ts
import { queueUiMap } from '../ui'

preload() {
    queueUiMap(this)
}
```

Шрифт `Galmuri7`, выбранный для проекта, не изменялся. До создания текстов
нужно дождаться его загрузки:

```ts
import { loadPixelFont } from '../ui'

await loadPixelFont()
```

После создания игровой сцены:

```ts
import {
    DEFAULT_MAP_LOCATIONS,
    GameUI
} from '../ui'

let ui: GameUI

ui = new GameUI(this, {
    onInventory: () => ui.showInventory(this, {
        slots: inventoryManager.getView()
    }),
    onMap: () => ui.showLocations(this, {
        locations: DEFAULT_MAP_LOCATIONS,
        onSelect: (sceneKey) => {
            this.scene.start(sceneKey)
        }
    }),
    onJournal: () => ui.showNotebook(
        this,
        journalManager.getChapterView()
    )
})
```

UI не вызывает `inventoryManager.add`, не расставляет предметы и не определяет,
какая локация доступна. Эти данные и действия приходят из игровой логики.

## Карта

Файл карты:

`src/ui/assets/city-map.png`

Он используется без перерисовки. Поверх картинки находятся прозрачные
кликабельные прямоугольники. Стандартные соответствия:

| Область карты | Ключ сцены |
|---|---|
| Дом | `children_room` |
| Гараж | `garage` |
| Школа | `classroom` |
| Пляж | `beach` |

Если ключи сцен изменятся, игровая команда может передать другой массив
`MapLocationView[]`. Переход выполняется колбэком `onSelect`; UI только
возвращает выбранный ключ.

У локации есть состояния:

- обычная;
- текущая — видна тонкая цветная рамка;
- закрытая — клик отключён.

## Рюкзак

На основном игровом экране предметы не отображаются. Модальное окно принимает
до шести карточек `InventorySlotView`.

Пока иллюстраций предметов нет, используется квадратная цветная заглушка.
Позже достаточно передать `iconKey` уже загруженной текстуры.

## Дневник

Дневник показывает список глав без отдельной иллюстрации. Для главы
поддерживаются состояния:

- `completed`;
- `current`;
- `locked`.

Когда появится рисунок дневника, его можно добавить внутрь
`notebook_UI.ts`, не изменяя игровую логику.

## UI-витрина

Запуск:

```bash
npm run dev-nolog
```

Адрес:

`http://localhost:8080/src/ui/preview.html`

Витрина сразу открывает игровой экран — стартового меню и дополнительного
клика нет.
