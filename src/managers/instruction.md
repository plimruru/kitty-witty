# Папка для логики

*Папка управляет логикой игры*

Структура папки: 

scenes/

    game_manager.ts

    dialogue_manager.ts 
*хранит какой диалог сейчас, какая реплика, какой персонаж что говорит*

    scene_manager.ts
*Какая сцена сейчас идёт*

    audio_manager.ts
*управляетт какая музыка сейчас играет, громкость и тд*

    save_manager.ts

    inventory_manager.ts 
*что есть в инвенторе персонажа*
